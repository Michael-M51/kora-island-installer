# Kora Island

A free Windows desktop island with media controls, a clipboard, notes, timers, local dictation and translation, file sharing, and optional pixel-art companions.

[Download the Windows installer](https://github.com/Michael-M51/kora-island-installer/releases/latest/download/KoraIsland-Setup.exe)

Run `KoraIsland-Setup.exe` to install for your Windows account. Built for Windows 11 x64. Voice is included; speech and translation models are separate downloads. Translation runs on your CPU. Optional Voice post-processing uses the provider you configure.

This is an experimental, unsigned build. Windows may show an unknown-publisher warning. License notices are included in the installation.

This repository contains the README and installer releases. Application source is not published here.
